## Before opening an issue

1. Read the [Usage guide (EN)](docs/en/usage.md) or [Hướng dẫn sử dụng (VI)](docs/vi/huong-dan-su-dung.md) — especially the troubleshooting section.
2. Search [existing issues](https://github.com/hitechcloudvn/ddns_admin_whitelist/issues) to avoid duplicates.
3. Collect environment details: WHMCS version, PHP version, module version, and relevant entries from `mod_ddns_admin_whitelist_logs`.

## What to include in a bug report

- Module version (see CHANGELOG or the addon module list in WHMCS admin)
- WHMCS and PHP versions
- Steps to reproduce
- Expected vs. actual behavior
- Relevant log rows from the module's activity log (redact private hostnames/IPs if needed)

## Scope of free support

Free support via issues covers confirmed bugs and documentation gaps. Deployment assistance, custom development, and priority response are available as **commercial support** — contact [info@photuesoftware.com](mailto:info@photuesoftware.com).
